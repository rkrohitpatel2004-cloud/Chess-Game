# GitHub Setup

## 1. Create a repository

Create a new GitHub repository named `cpp-chess-game`.

Do not add another README, `.gitignore`, or license if you are uploading this project as-is.

## 2. Open Terminal in this project folder

```bash
git init
git add .
git commit -m "Initial commit: C++ chess game"
git branch -M main
git remote add origin YOUR_REPOSITORY_URL
git push -u origin main
```

Replace `YOUR_REPOSITORY_URL` with the URL of your GitHub repository.

## 3. Future updates

```bash
git add .
git commit -m "Update chess game"
git push
```
